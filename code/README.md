# Code layout

analysis/ contains current production scripts plus a portable filesystem helper. label_derivation/ contains primary-only source interfaces. figures/ contains the final presentation compositor, figure entry points and calibration display. Read documentation/ANALYSIS_WORKFLOW.md before execution. label_derivation/hrs_recognition.py is a side-effect-free HRS mapping helper used by the actual primary adapter and synthetic tests. It applies the audited CORR01 change for 2018 QC005 while retaining 2014 OC005; no source data are read by the helper. Scientific scripts must run in an authorized local environment; do not import them for structural tests because they execute analyses at module level.

## CORR01 synthetic checks
From the repository root, run `python -m unittest discover -s tests -v` in an environment with pandas and NumPy installed (see environment/requirements.txt). The original dependency-free suite remains available as `python tests/test_public_structure.py`. Synthetic checks compile only selected function definitions from the actual adapter, excluding its top-level data-processing code, and compare authorized behavior with the immutable public baseline. No licensed source files, private configurations or scientific pipelines are loaded. Passing these checks does not establish end-to-end numerical reproduction.
